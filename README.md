# Учёт личных расходов студента

Рабочий прототип: одностраничное веб-приложение, всё считается на клиенте, данные хранятся в браузере. Без ИИ, без внешних API, без бэкенда.

## Запуск

Вариант 1 - открыть по ссылке (опубликованная версия работает сразу в браузере).

Вариант 2 - локально:
1. Сохранить файл `tracker.html`.
2. Открыть двойным кликом в любом современном браузере.

Установка и сборка не нужны - один HTML-файл, всё внутри.

## Что реализовано

Базовое (по ТЗ):
- Форма: сумма, категория, дата, описание (необязательно).
- Валидация: сумма только положительным числом, категория и дата обязательны; при ошибке - понятное сообщение, запись не добавляется.
- Список за выбранный период, удаление любой записи (с кнопкой «Вернуть» 5 секунд).
- Общий итог и разбивка по категориям с процентами; сумма категорий равна итогу.
- Пересчёт при добавлении, удалении и смене периода.
- Хранение в браузере (localStorage), данные остаются после обновления страницы.
- Одна валюта (₸), без конвертации.

Дополнительно:
- Периоды анализа: месяц, 3 месяца, полгода, год, всё время, свой диапазон дат. Итоги, средний расход в месяц и помесячная динамика столбиками.
- Способ оплаты (Kaspi, Halyk, Freedom, наличные, карта) как поле и отдельная разбивка «по способам».
- Разбор чека или выписки текстом: вставляешь текст, приложение по правилам-ключевикам (такси→транспорт, magnum→еда, аптека→здоровье и т.д.) вытаскивает суммы и раскидывает по категориям; ты правишь и подтверждаешь. Работает без ИИ и без API - на словаре правил.
- Автоподсказка категории по описанию при ручном вводе.
- Быстрый ввод: способ оплаты запоминается между записями, фокус сразу на сумму.
- Светлая и тёмная тема, адаптив под телефон.

## Проверочный пример

За один месяц: еда - 1500, транспорт - 600, еда - 900.
Ожидаемо: всего 3000, еда - 2400, транспорт - 600.
Удалить расход на 900: итог 2100, еда - 1500.

## Что не сделано и почему (граница ТЗ)

- Автоматически подтягивать оплаты из Kaspi/Halyk/Freedom, чтобы не открывать приложение при каждой трате - невозможно без доступа к банкам, это внешние API. В прототипе оставлен только быстрый ручной ввод и разбор выписки текстом.
- Автоматически распознавать фото чека/товара и самому относить в категорию - это распознавание изображений, то есть ИИ. Вместо этого - разбор текста по фиксированным правилам, где категорию можно поправить руками.

## Ограничения

- Нет регистрации, синхронизации между устройствами, банковских интеграций и реальных платежей.
- Данные привязаны к одному браузеру на одном устройстве. Очистка данных сайта удаляет записи.
- Категории и способы группируются по точному совпадению названия. Разбор текста - по словарю ключевых слов, редкие формулировки попадают в «Прочее».
